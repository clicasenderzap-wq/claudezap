## [CORREÇÃO] Campo de destinatário na página Mensagens não aceitava digitação
**Problema:** Campo de número/contato na página de envio individual usava um `<div>` estilizado como input (componente `ContactPicker`) — a maioria das vezes não deixava digitar.
**Solução:** Substituição por um `<input>` real com autocomplete inteligente: digitar nome filtra contatos, digitar números é aceito diretamente como número manual. Removido o toggle "Selecionar contato / Digitar número".
**Arquivos:** `frontend/src/app/(dashboard)/(whatsapp)/messages/page.tsx`
**Commit:** `979a3be`

## [CORREÇÃO] Mensagens travadas em "Na fila" nunca enviavam
**Problema (3 causas simultâneas):**
1. UI não atualizava automaticamente para mostrar o progresso
2. Após restart do servidor (Render reinicia a cada deploy), mensagens `queued` no banco não eram re-enfileiradas imediatamente — app Electron não tinha tempo de reconectar
3. Quando o app Clica Aí estava offline, mensagem falhava permanentemente em vez de aguardar reconexão
**Solução:**
1. `refetchInterval` dinâmico na query de histórico — atualiza a cada 4s quando há mensagens em fila
2. Grace period de 90 segundos no startup antes de disparar jobs — dá tempo para o Electron reconectar
3. Worker detecta "app offline" e re-agenda a mensagem para daqui a 3 minutos
**Arquivos:** `backend/src/app.js`, `backend/src/workers/messageWorker.js`, `frontend/src/app/.../messages/page.tsx`
**Commit:** `42a6ee5`

## [CORREÇÃO] Rastreamento de confirmações de entrega do WhatsApp
**Problema:** Sistema não atualizava o status para "Entregue" quando o WhatsApp confirmava. Mensagens ficavam como "Enviado" para sempre.
**Solução:** Listener no Baileys para evento `message_delivered` → atualiza status no banco para `delivered`.
**Commit:** `a3fd55e`

## [NOVO RECURSO] Filtro "Sem confirmação" no modal de campanha
**Solução:** Nova aba no detalhe da campanha separando mensagens enviadas mas sem confirmação de entrega.
