# 21/05/2026

## [CORREÇÃO] Modal QR fecha imediatamente após conexão
**Problema:** Após escanear o QR, o modal demorava até 8s para fechar (interval de polling).
**Solução:** Poll a cada 3s quando modal QR está aberto.
**Commit:** `ac5f113`

## [CORREÇÃO] Mensagens do WS perdidas durante autenticação
**Problema:** Eventos como `ready` chegavam antes da autenticação completar no backend e eram descartados.
**Solução:** Buffer de mensagens WS — acumula durante auth e processa logo após.
**Commit:** `1bfef8a`

## [NOVO RECURSO] Versão mínima automática = sempre a última do GitHub
**Solução:** Backend consulta a API do GitHub para saber qual é a versão mais recente e usa ela como mínima. Remove necessidade de atualizar manualmente no admin.
**Commit:** `53080f8`
