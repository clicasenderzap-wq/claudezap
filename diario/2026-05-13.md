# 13/05/2026

## [CORREÇÃO] Pool de conexões do banco esgotava durante resumo de campanha
**Problema:** `resume()` atualizava cada mensagem individualmente, abrindo centenas de conexões simultâneas.
**Solução:** `Message.update()` em bulk (uma SQL só para todas as mensagens).
**Commit:** `fc54600`

## [MELHORIA] UI de progresso de lotes mais clara
**Solução:** Barra de progresso por lote mostrando mensagens enviadas / total do lote.
**Commit:** `f77f6a6`

## [CORREÇÃO] Redução de polling para economizar cota do Render
**Problema:** Muitas queries por segundo estavam consumindo a cota de transferência do plano gratuito.
**Solução:** Polling reduzido de 3s para 8-15s nas queries de status.
**Commit:** `ed1a430`

## [CORREÇÃO] Coluna `session_token` precisava existir antes do sync do Sequelize
**Problema:** Migration rodava depois do sync, causando erro na inicialização.
**Commit:** `971bef4`
