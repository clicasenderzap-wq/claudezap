## [INFRAESTRUTURA] Migração de Redis/BullMQ para PostgreSQL/fila própria
**Problema:** Redis estava custando dinheiro extra e era um ponto de falha adicional. BullMQ exigia Redis.
**Solução:** Substituição por fila simples em memória com `setTimeout` + tabela de mensagens no PostgreSQL como persistência. Custo zero adicional.
**Arquivos:** `backend/src/services/queueService.js` (reescrito), `backend/src/workers/messageWorker.js`
**Commit:** `3ac67cc`

## [INFRAESTRUTURA] Migração de whatsapp-web.js para Baileys
**Problema:** whatsapp-web.js usava Puppeteer + Chrome — pesado demais para o servidor gratuito do Render. Consumia 500MB+ de RAM.
**Solução:** Migração para Baileys (conexão direta via protocolo WhatsApp, sem browser). Muito mais leve.
**Arquivos:** `electron-app/src/waManager.js` (reescrito), `electron-app/package.json`
**Commit:** `40121c1`

## [CORREÇÃO] Baileys é ESM — incompatível com require()
**Problema:** Baileys v6 é um módulo ESM puro mas o projeto usa CommonJS.
**Solução:** `import()` dinâmico para carregar Baileys de forma compatível.
**Commit:** `8ce342f`

## [CORREÇÃO] Socket zombie no Baileys + makeCacheableSignalKeyStore
**Problema:** Conexões antigas ficavam abertas (zombie) após desconexão. API do Baileys mudou.
**Commit:** `6090c66`
