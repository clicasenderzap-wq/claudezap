# Diário do Projeto — Clica Aí

Registro diário de todas as correções, melhorias e ações realizadas no sistema.

## Como usar

- Um arquivo por dia de trabalho: `YYYY-MM-DD.md`
- Cada entrada descreve **o que foi feito**, **por que foi feito** e **quais arquivos foram alterados**
- Ao iniciar uma nova sessão de trabalho, criar/atualizar o arquivo do dia atual

## Estrutura de cada entrada

```
## [TIPO] Título da ação
**Problema:** descrição do problema ou motivação
**Solução:** o que foi feito
**Arquivos:** lista dos arquivos alterados
**Commit:** hash do commit (se aplicável)
```

Tipos: `CORREÇÃO` | `MELHORIA` | `NOVO RECURSO` | `INFRAESTRUTURA` | `DOCUMENTAÇÃO`
